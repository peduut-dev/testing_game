# Zombie FPS Multiplayer - Gedung Pemerintahan Indonesia

Game FPS multipemain sederhana berbasis web (raycasting) dengan tema gedung pemerintahan Indonesia.

## Fitur
- Multiplayer real-time via WebSocket.
- Zombie spawn acak dan bergerak mengejar pemain.
- Upgrade senjata (damage, fire rate, kapasitas).
- Item acak: peluru dan obat.
- Item tetap: kunci untuk membuka pintu terkunci.
- Senjata tersembunyi yang bisa ditemukan.
- Latar gedung pemerintahan Indonesia.

## Menjalankan
```bash
npm install
npm start
```

Lalu buka `http://localhost:3000` di beberapa tab/browser untuk multiplayer.
